# 4.2.1 Levantamento de Requisitos

## 1. Como os requisitos foram levantados
Os requisitos foram levantados por meio de uma entrevista com o colecionador/gamer (dono da coleção) para compreender as dores no gerenciamento dos jogos, bem como pela análise do comportamento de amigos e visitantes que consultam a lista de jogos disponíveis.

---

## 2. Da fala à necessidade
| ID | Fala do Cliente | Classificação | Necessidade por trás |
| :--- | :--- | :--- | :--- |
| **F01** | "Eu tenho um monte de jogo e nunca sei direito o que eu tenho, o que já terminei ou pra quem eu emprestei." | Necessidade | Centralizar as informações da coleção de jogos e seu histórico em um único local. |
| **F02** | "Acabo comprando jogo repetido ou perdendo meus jogos por aí." | Necessidade | Controlar a localização (em casa x emprestado) e o catálogo de jogos cadastrados. |
| **F03** | "Acho qualquer informação sobre eles em menos de 10 segundos..." | Necessidade Implícita | Fornecer busca e filtros rápidos por plataforma, gênero ou status. |
| **F04** | "Anoto para quem emprestou e o dia que ele tem que devolver." | Necessidade | Registrar empréstimos associando o nome do amigo e a data limite de devolução. |
| **F05** | "Para mexer na coleção precisa de login e senha, mas os amigos podem ver se tiverem o link." | Solução | Implementar autenticação para edição e permissão de visualização pública via link compartilhado. |

---

## 3. Histórias de Usuário
* **US01:** Como **dono da coleção**, quero **cadastrar novos jogos informando nome, plataforma, gênero e mídia (física ou digital)**, para **manter meu inventário atualizado e evitar comprar jogos repetidos**. *(Origem: F01, F02)*
* **US02:** Como **dono da coleção**, quero **registrar empréstimos informando o nome do amigo e a data prevista de devolução**, para **saber exatamente onde meus jogos estão e não perdê-los**. *(Origem: F02, F04)*
* **US03:** Como **dono da coleção**, quero **alterar o status do jogo (ex.: "Jogando", "Zerado", "Emprestado")**, para **acompanhar meu progresso e disponibilidade dos jogos**. *(Origem: F01)*
* **US04:** Como **dono da coleção e visitante**, quero **filtrar e buscar jogos por categoria ou plataforma**, para **encontrar qualquer jogo em menos de 10 segundos**. *(Origem: F03)*
* **US05:** Como **visitante/amigo**, quero **acessar a lista de jogos através de um link público (sem precisar editar)**, para **saber quais jogos o dono possui e quais posso pedir emprestado**. *(Origem: F05)*

---

## 4. Requisitos Funcionais (RF)
| Código | Nome | Descrição do Requisito | Origem |
| :--- | :--- | :--- | :--- |
| **RF01** | Cadastrar Jogo | O sistema deve permitir ao dono cadastrar jogos com nome, plataforma, gênero e tipo de mídia (física ou digital). | US01 |
| **RF02** | Registrar Empréstimo | O sistema deve permitir registrar empréstimo vinculando o jogo ao nome do amigo e definindo a data limite de devolução. | US02 |
| **RF03** | Atualizar Status do Jogo | O sistema deve permitir alterar a situação do jogo entre "Jogando", "Zerado" e "Emprestado". | US03 |
| **RF04** | Buscar e Filtrar Jogos | O sistema deve permitir pesquisar jogos por nome e filtrar por gênero ou plataforma. | US04 |
| **RF05** | Autenticar Utilizador | O sistema deve exigir login e palavra-passe para que apenas o dono faça alterações na coleção. | US01, US02, US03 |
| **RF06** | Compartilhar Lista Pública | O sistema deve disponibilizar uma visualização somente-leitura da coleção para visitantes via hiperligação/link. | US05 |

---

## 5. Requisitos Não Funcionais (RNF)
| Código | Categoria | Descrição do Requisito | Origem |
| :--- | :--- | :--- | :--- |
| **RNF01** | Usabilidade / Responsividade | O sistema deve ser executado no navegador da web com interface adaptada tanto para telemóveis quanto para computadores. | Seção 4.1 |
| **RNF02** | Desempenho | As buscas e o carregamento das listas de jogos devem responder em menos de 3 segundos. | F03, Seção 4.1 |
| **RNF03** | Segurança | As operações de modificação de dados (criar, editar, eliminar) devem ser protegidas por autenticação com palavra-passe. | F05 |

---

## 6. Conferência com a Seção 4.1
| Item do Escopo (Seção 4.1) | Requisitos Funcionais Que Atendem |
| :--- | :--- |
| O sistema cadastra novos jogos marcando o nome, videogame/plataforma, gênero e se é mídia física ou digital. | RF01 |
| O sistema anota os empréstimos, guardando o nome do amigo e o dia que ele tem que devolver. | RF02 |
| O sistema muda o status do jogo (exemplo: "Jogando", "Zerado" ou "Emprestado"). | RF03 |
| O sistema procura os jogos por categoria, como gênero ou videogame. | RF04 |

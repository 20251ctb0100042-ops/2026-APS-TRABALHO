# 4.2.3 Modelagem de Classes

## Dos substantivos às classes

As classes saem dos substantivos. A fonte principal é o fluxo do caso de uso *Cadastrar e Gerir Ingredientes*, especificado na 4.2.2. Cada elemento que o ator informa ou que o sistema valida e confirma é algo que o sistema precisa guardar. A segunda fonte é a lista de requisitos da 4.2.1. O que aparece em ambas vira classe com elevado nível de confiança.

Nem todo substantivo vira classe. Aplicam-se três filtros: o que é detalhe de outra coisa vira atributo (o prazo de validade é de um lote específico). O que é interface não entra (ecrã de cadastro, botão guardar, alerta de stock baixo). O que está fora do sistema também não (a prateleira da despensa, o bloco de notas de compras).

| Substantivo | De onde veio | Vira | Por quê |
|---|---|---|---|
| funcionário / utilizador | passo 1 do fluxo, HU01, RF01 | classe **Utilizador** | o sistema regista quem acede ao módulo e autoriza alterações de stock |
| gestor de stock / cozinheiro | ator da 4.2.2, passo 1, RNF02 | classes **GestorStock** e **Cozinheiro** | sobem para a classe geral **Utilizador**, mas mantêm permissões distintas |
| ingrediente | passo 3, RF02, RF03 | classe **Ingrediente** | a definição do item no catálogo (ex.: Farinha de Trigo, Açúcar, Ovos) cadastrado e consultado pelo utilizador |
| lote | passo 4 ("o lote está dentro da validade"), exceção E2, e a 4.1 | classe **LoteIngrediente** | a cozinha pode ter três lotes de Farinha de Trigo com datas de validade distintas. O que sai no consumo é um lote específico. Esta classe nasceu da especificação do fluxo físico de stock |
| movimento de stock | passo 7, RF05, RF06 | classe **MovimentoStock** | o registo que substitui o papel: entrada, saída ou perda de um lote (quem, quanto, qual lote e motivo) |
| fornecedor | passo 3, RF04 | classe **Fornecedor** | empresa ou entidade que fornece determinado ingrediente para o estabelecimento |
| data de validade | passo 5, RF07 | atributo de **LoteIngrediente** | é um detalhe de um lote físico específico, não existe de forma isolada |
| prateleira, bloco de notas | falas da 4.2.1 | nada | estão fora do sistema físico de software. O bloco de notas é o processo manual a ser substituído |

## Classes

Seis classes principais formam a estrutura do módulo. Cada uma conta com três faixas: nome no singular com inicial maiúscula, atributos no formato `nome: tipo` e operações com parênteses. Cada elemento possui a sua rastreabilidade direta com os requisitos e passos do fluxo.

Em relação às primeiras explorações do domínio, a classe `Ingrediente` perdeu o atributo `fornecedorPadraoString`, pois a relação de fornecimento é gerida pela associação com a classe `Fornecedor`. Além disso, a movimentação de stock (`MovimentoStock`) passou a ligar-se diretamente a `LoteIngrediente` e não a `Ingrediente` genérico, visto que a rotatividade de stock (FIFO/PEPS) exige baixa por lote e validade.

| Classe | Atributos | Operações | Veio de |
|---|---|---|---|
| **Utilizador** | - nome: String, - matricula: String, - perfil: String | + autenticar(): boolean | passo 1 (identificação), RNF02 (acesso restrito) |
| **GestorStock** | _herda de Utilizador_ | + aprovarAjuste(): void | RNF02: apenas o gestor pode aprovar perdas ou ajustes manuais |
| **Ingrediente** | - nome: String, - unidadeMedida: String, - stockMinimo: double | + verificarStockBaixo(): boolean, + getStockTotal(): double | RF01 (cadastro do item), RF03 e passo 4 (alerta de ponto de encomenda) |
| **LoteIngrediente** | - codigoLote: String, - dataValidade: Data, - quantidadeAtual: double | + darBaixa(qtd: double): void, + estaVencido(): boolean | passo 7 ("atualiza a quantidade do lote"), RF04, exceção E2 |
| **MovimentoStock** | - dataHora: DataHora, - quantidade: double, - tipoMovimento: TipoMovimento | + registrarMovimento(): void | passo 5 e RF07 (registo da ação), RF06 (histórico de consumo) |
| **Fornecedor** | - razaoSocial: String, - cnpj: String, - telefone: String | + listarIngredientesFornecidos(): List | RF04 (vínculo com o fornecimento do acervo de matéria-prima) |
